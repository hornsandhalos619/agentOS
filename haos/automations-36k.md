# Save-36K stack — OpenClaw and Hermes

Same five jobs. Two runtimes. Drafts only. Free pipes.

OpenClaw home: default claw config + `/openclaw` + crew panel.
Hermes home: `$HOME/.haos/hermes-quick` (kit 8). Do not mix homes.

Install OpenClaw (owner machine):
`npm install -g openclaw@latest` then `openclaw onboard --install-daemon`
Point model at OmniRoute `http://localhost:20128`.

## 1 Content machine — 8am weekdays
Voice: Horns & Halos, direct, no corporate. Pillars: merch, occult/fantasy art, affiliate gear, HA.OS.
Output: 1 caption, 3 X lines. Save drafts. Do not post.
OpenClaw message or Hermes cron in hermes-quick/automations.md.

## 2 Lead pipeline — 6am weekdays
ICA: print-on-demand / indie merch / occult-art buyers and small shops, not $15K agencies.
10 rows: name, site, pain line. `$HERMES_HOME/leads` or claw `~/leads`.

## 3 Outreach engine — 2pm weekdays
Top 3 from today's leads. 75-word draft. Human send only.

## 4 Intel — 5:30am weekdays
Three merch comps + one product to feature. 120 words.

## 5 Admin — 7am weekdays
