# Agent Business in a Box — what can actually auto

Cannot fully automate a business. The PDF is an offer + pricing + DM scripts wrapper.
A machine does not accept liability, take payments honestly, or ship merch.

What HA.OS can loop without you in the chair:
- draft content / leads / intel / admin (kit 12 crons)
- write listing variants (prompt 007)
- price-watch affiliate SKUs (kit 27 #6)

What stays human:
- publish, send, charge, refund, legal, platform bans
- any message that leaves the building

Do not load the $1.5K/$5K/$10K tiers into the UI as if they are live products.
If the shop later needs an offer line, use merch + affiliate, not "I build agents for agencies."
